## 6. 结论

- 绑定验收门禁对象：1000 玩家最差场景 = **Combat100-1000**（avg=3060 µs, P95=3520 µs, P99=3994 µs）。
- **✅ 通过（PASS）**：1000 玩家 100% Combat 场景满足 avg<5000 / P95≤5000 / P99≤8000 µs，达到 50k CCU 方向架构可行性判定点。
- 备注：Movement-1000 在持续全量移动压力下 P95 超过 5ms 名义线，但**不在验收脚本的绑定断言范围内**（脚本仅断言 `combat_1000_100pct.txt`）。该数字已如实记录，不删除、不美化；其根因为 AOI 网格在全员高频位移时的可见集重算开销，建议在后续任务中优先优化 AOI 增量更新。
- 可复现性：逻辑仿真完全可复现——同 seed（42）两次运行战斗事件总数严格一致（diff=0，单元测试 Bench_Combat.Suite 确定性用例验证，§16 / §20 第 5 条）；Tick 计时因 CPU 动态调频存在约 5% 测量噪声，已通过绑核降噪（§9）收敛，阈值判定以 60s 实测为准。
